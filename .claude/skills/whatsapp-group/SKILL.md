# כלי קבוצות וואטסאפ

מנוע הביצוע: `whatsapp-tool/group_export.js` (whatsapp-web.js + Chromium מקומי).
הוא מתחבר עם **סשן נפרד** (clientId: `grouptool`) כדי **לא לפגוע בבוט** הראשי שרץ.

## מצבי הרצה
מריצים מתוך תיקיית `whatsapp-tool`:

```
node group_export.js list "<שם קבוצה>"            # מחלץ חברי קבוצה ספציפית → group_members.txt + .json
node group_export.js create "<שם חדש>" <numbers.txt>  # יוצר קבוצה עם המספרים בקובץ
node group_export.js groups                          # מציג את כל הקבוצות (להשתמש רק אם דין מבקש במפורש)
```

## זרימת עבודה מומלצת (פתיחת קבוצה חדשה)
1. **חיבור:** הרץ פעם אחת כל מצב. אם הסשן לא מחובר → ייווצר QR ב-`whatsapp-tool/grouptool_qr.png`. פתח אותו למשתמש עם `Start-Process` והנחה אותו לסרוק.
2. **חילוץ מקור (אם פותחים על בסיס קבוצה קיימת):** `list "<שם>"` → הצג לדין רשימה ממוספרת מסודרת (שם + מספר, וסמן 👑 מי מנהל).
3. **מיון בצ'אט:** דין אומר מי לנפות/להוסיף. **התכתב איתו עד שהרשימה מאושרת — אל תפתח קבוצה לפני אישור מפורש.**
   - אם ביקש להוריד מאמן שלא קיים ברשימה — פשוט התעלם, אל תעיר.
4. **יצירה:** כתוב קובץ `new_group_numbers.txt` עם המספרים בפורמט `9725XXXXXXXX` (אחד בשורה), והרץ `create`.
5. **דווח:** סכם כמה נוספו, ומי (אם בכלל) קיבל הזמנה במקום הוספה ישירה (`isInviteV4Sent: true`).

## כללי זהב / לקחים
- **לא להוסיף את המספר של דין** (`972525320400`) לרשימת המשתתפים ב-create — הוא נכנס אוטומטית כיוצר/מנהל. הוספה כפולה עלולה לשבור.
- **QR נסרק רק מתוך וואטסאפ** (מכשירים מקושרים → קישור מכשיר), **לא** ממצלמת הטלפון — מצלמה רגילה מציגה "לינק שבור".
- **לא להציף ניסיונות קישור.** ריבוי QR/ניתוקים בזמן קצר → וואטסאפ חוסם זמנית ("אי אפשר לקשר מכשירים כרגע"). אם זה קורה: לעצור הכל, לחכות 15–30 דק'. בדיקה מכריעה — לנסות `web.whatsapp.com` הרשמי: אם גם שם נכשל → חסימת חשבון (לחכות); אם שם מצליח → הבעיה בכלי.
- **הסשן נשמר** אחרי סריקה ראשונה (`.wwebjs_auth/session-grouptool`) — פעולות הבאות ללא QR.
- **פרטיות:** אל תדמפ את כל הקבוצות של דין אלא אם ביקש במפורש. מצב `list` מוציא רק את הקבוצה המבוקשת.
- שמות חברים נמשכים מאנשי הקשר; מי שלא שמור מסומן "(לא שמור באנשי קשר)" — להציג לפי מספר.
- **לא להתבלבל בין שמות דומים** (למשל "חי מולטיסקילס" מול "חי ניר") — לאמת מול המספר.

## הרצה ברקע + QR
- הרץ ברקע, המתן שייווצר `grouptool_qr.png`, ואז `Start-Process` עליו.
- כש-`list`/`create` מסיימים — node יוצא לבד (exit 0) ושומר את קבצי הפלט.

## הרחבות אפשריות (לא ממומשות עדיין)
- מינוי מנהלים אוטומטי (`group.promoteParticipants`).
- הוספת חברים לקבוצה קיימת.
- אם דין מבקש אחת מאלה — להוסיף מצב מתאים ל-`group_export.js`.
