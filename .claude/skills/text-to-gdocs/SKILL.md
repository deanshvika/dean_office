# העברת טקסט ל-Google Docs

הדרך **האמינה** להפוך תוכן מעוצב למסמך Google Docs. **אל תנסה הדבקה ישירה** (Clipboard HTML + Ctrl+V לתוך דוקס פתוח) — גוגל דוקס לא קולט אותה וזה מבזבז זמן. השיטה שעובדת: **HTML → DOCX (Word COM) → העלאה ל-Drive → פתיחה כמסמך גוגל.**

מנוע הביצוע: `html_to_gdoc.ps1` (בתיקיית הסקיל).

## זרימת עבודה

1. **כתוב HTML** עם `dir="rtl"` בגוף ובכל כותרת/טבלה, `text-align:right`, פונט Arial. כותרות `<h1>/<h2>/<h3>`, רשימות `<ul>`, טבלאות `<table border=1>`. שמור לקובץ `.html` בתיקיית העבודה.

2. **המר ל-DOCX:**
   ```
   powershell -File .claude/skills/text-to-gdocs/html_to_gdoc.ps1 -Step convert -Html "<path.html>" -Docx "<out.docx>"
   ```
   מצפה ל-`CONVERT_OK`. (משתמש ב-Word COM; Word מותקן במחשב.)

3. **העלה ל-Drive (רצף אטומי):**
   ```
   powershell -File .claude/skills/text-to-gdocs/html_to_gdoc.ps1 -Step upload -Docx "<out.docx>" -Shot "<verify.png>"
   ```
   הסקריפט: פותח **חלון כרום חדש** ל-Drive → לוחץ "חדש +" → "העלאת קבצים" → ממתין זמן קבוע → מדביק את נתיב ה-docx **בעיוור** → Enter → מצלם מסך. הכל ברצף אחד.

4. **אמת** — קרא את קובץ ה-`-Shot`. צריך לראות "העלאה אחת הושלמה" עם שם הקובץ.

5. **פתח כמסמך גוגל** — קליק על שם הקובץ בהודעת ההשלמה (פינה שמאלית-תחתונה, ~0.145,0.954 מהחלון). הקליק מפעיל את חלון כרום ופותח את הקובץ בטאב חדש כמסמך גוגל (מצב תאימות DOCX, ערוך לגמרי). אפשר לצלם שוב לאימות (`-Step shot`).

## כללי זהב / לקחים (נלמדו בדם)

- **תמיד לאמת עם צילום מסך** (`CopyFromScreen` → PNG → קרא אותו). בלי אימות ויזואלי אי אפשר לדעת אם קליק/הדבקה תפסו.
- **VS Code = Electron = אותה מחלקת חלון כמו Chrome** (`Chrome_WidgetWin_1`), והוא **חוטף פוקוס בין קריאות נפרדות**. לכן: (א) כל רצף ההעלאה חייב לרוץ **בסקריפט אחד**; (ב) בדיקת "האם כרום בחזית" לפי מחלקה **לא אמינה** — VS Code נראה זהה.
- **`SetForegroundWindow` מתהליך רקע נחסם ע"י Windows** — לכן פותחים `chrome.exe --new-window` (חלון חדש עולה לחזית לגיטימית), וסומכים על **הקליק** להפעיל את החלון (קליק מפעיל את החלון שמתחת לעכבר בלי צורך בפוקוס מוקדם).
- **הדבקה עיוורת, לא FindWindow.** `FindWindow("#32770")` **לא** זיהה את חלון בחירת הקובץ של Chrome באמינות. במקום זה — להמתין זמן קבוע אחרי הקליק על "העלאת קבצים" (הדיאלוג הוא החלון הפעיל) ולהדביק בעיוור.
- **פוקוס וקואורדינטות** — הקואורדינטות שברים מחלון **ממוקסם**. אם הקליק מפספס — צלם, מצא מיקום חדש, תקן. "חדש +" בפינה **ימנית**-עליונה (RTL).
- **ניקוי** — אחרי שהמסמך פתוח ב-Docs, מחק `_verify_*.png` וה-`.html` הביניים. השאר `.docx` ו-`.md`.

## למה זה עובד ומה לא

| ניסיון | תוצאה |
|--------|--------|
| הדבקת HTML מהלוח + Ctrl+V לדוקס פתוח | ❌ נכשל — דוקס לא קולט |
| קליק בגוף העמוד + Ctrl+V | ❌ נכשל |
| `SetForegroundWindow` לכרון קיים מתהליך רקע | ❌ נחסם ע"י Windows |
| `FindWindow("#32770")` לזיהוי הדיאלוג | ❌ לא אמין |
| `chrome --new-window` + קליקים + **הדבקה עיוורת** + Enter, בסקריפט אחד | ✅ עובד |
| HTML → DOCX (Word COM) → העלאה ל-Drive | ✅ עובד |
