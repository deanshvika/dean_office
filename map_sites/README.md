# map_sites — מפת המוקדים הגאוגרפית

מייצר את `מפת_מוקדים.html` — מפה אינטראקטיבית של כל מוקדי ניקה, צבועה לפי ודאות שיבוץ המאמן.

## הרצה

```
node map_sites/build_sites_geo.js   # רוסטר + גיאוקודינג → sites_geo.json
node map_sites/build_map.js         # sites_geo.json → מפת_מוקדים.html
node map_sites/shoot.js             # אימות: צילומי מסך + בדיקות חפיפה וגלישה
```

השלב השני והשלישי מספיקים אם רק העיצוב השתנה. השלב הראשון פונה לרשת ולוקח כדקה.

## מקורות המיקום

| מקור | מה נותן |
|---|---|
| GIS עיריית ת"א, שכבה **769** (בתי ספר תשפ"ז) | כתובת רשמית + קואורדינטת ITM + סמל מוסד + טלפון, ל-13 מוקדי ת"א/יפו. תומך `layerWhere` בסגנון SQL |
| GIS עיריית ת"א, שכבה **511** (שכונות) | 71 מצולעי שכונות ב-ITM. משמש גם לשיוך שכונה לכל מוקד (point-in-polygon) וגם כרקע המפה |
| data.gov.il `5c5d6bb0-…` (קואורדינטות מוסדות חינוך) | lat/lon ארצי לפי סמל מוסד, ל-13 המוקדים מחוץ לעיר |
| OpenStreetMap / Overpass | קו חוף, נחל הירקון, נתיבי איילון (`osm_base.json`) |
| Nominatim | גיאוקודינג הפוך להשלמת כתובות רחוב מחוץ לת"א |

`sites_geo.json` הוא הפלט השמיש בפני עצמו — לכל מוקד יש `lat/lon`, כתובת, שכונה, אשכול נסיעה, ימים, שעות, מאמן וודאות.

## מלכודות שכבר נפלנו בהן

- **ITM אינו lat/lon.** שכבות העירייה מחזירות `wkid 2039`. ההמרה ב-`geo_util.js`, מאומתת מול נקודות ידועות עד 23 מטר.
- **`UTM_X`/`UTM_Y` במאגר משרד החינוך הם lon/lat**, למרות השם.
- **כתיב מלא מול חסר.** `נווה זמר` מחזיר אפס תוצאות; במאגר זה `נוה זמר`. `ktivChaser()` מטפל.
- **שמות בתי ספר אינם ייחודיים ארצית.** `מרחבים` מחזיר 11 תוצאות. חובה סינון לפי תיבה תוחמת עירונית (`CITY_BBOX`), ולמקרים שנשארים עמומים יש `semelOverride` עם `verifiedBy` שמתעד איך הוכרע.
- **`הבילויים` אינו במאגר משרד החינוך** תחת השם הזה. נקבע ידנית מ-OSM: מקיף ג׳ / חט"ב אחרון הבילויים, הבריגדה 12 ראשל"צ.
- **שדות המנהל/ת במאגר העירוני מכילים שני שמות מודבקים** בכל בית ספר. לא ניתן להפריד באמינות — לא מוצגים.
- **אומדן רוחב תו לתוויות** חייב להיות נדיב, אחרת תוויות "לא חופפות" נדפסות זו על זו. `shoot.js` מודד חפיפות אמיתיות ב-DOM.
- **`1–6` בטקסט עברי מתהפך ל-`6–1`.** כיתות מוצגות באותיות (`א׳–ו׳`).

## סתירה ידועה בין הגיליונות

גיליון המוקדים קובע סטטוס וודאות, גיליון השיבוץ קובע ימים/שעות/מאמן. איפה שהם נחלקים, שני הערכים מוצגים בכרטיס המוקד עם `⚠` ולא נבחר אחד בשקט.
