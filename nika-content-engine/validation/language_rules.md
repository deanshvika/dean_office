# language_rules — חוקי ולידציה לשוניים (שפה/אנגלית/ניקוד)

## ניקוד (לפי `system/niqqud_rules.md`)

- `niqqud: true` → כל מילה עברית גלויה MUST מנוקדת. חסר ניקוד → FAIL.
- `niqqud: false` → אף מילה עברית לא נושאת ניקוד. עודף → FAIL.
- בדיקה: סימני ניקוד בטווח U+05B0–U+05C7 (`hasNiqqud`).

## שפה

- כל מילה שמופיעה כפריט/מסיח MUST מ-`language_bank.word_pool` (אוצר סגור).
- אורך טקסט סביר לגיל; מספר משימות תואם לתבנית.

## אנגלית

- כל מילה באנגלית MUST מ-`english_bank.words` (אוצר סגור, בלי יצירתיות חופשית).
- NEVER קפיצה לרמת משפטים מורכבת.
- ההוראות בעברית (שכבה א') — מנוקדות.

## מבנה (כל עמוד תלמיד)

MUST כל האזורים: פתיח, מה עושים, דוגמה, משימות, מסר מחזק, בדיקה מהירה, "היום הצלחתי כי", בונוס. חסר אזור → לא תקין.
