# checklist — רשימת בדיקה לפני רינדור

- [ ] כל השדות העליונים קיימים (day_id, subject, audience, title, pages).
- [ ] כל עמוד תלמיד כולל את כל האזורים הקבועים.
- [ ] דף מדריך כולל את כל הסעיפים.
- [ ] **חשבון:** כל משימה עברה בדיקה מספרית (טווח + אריתמטיקה + ספירה=תשובה).
- [ ] **בונוס find_count** עקבי עם משימות העמוד.
- [ ] **ניקוד** תואם למדיניות השכבה/התחום.
- [ ] **אוצר סגור** (שפה/אנגלית) — אין מילים מחוץ לבנק.
- [ ] לכל פריט יש אייקון ב-`assets/icons/`.
- [ ] מותר להתקדם לרינדור? רק אם הכל ✔ (או `--force` מודע).

הבדיקות האוטומטיות: `node scripts/validate_page.mjs <day_id>`.

## בדיקה ידנית מדגמית אחרי הפקה (batch)

עמוד חשבון אחד · עמוד שפה אחד · עמוד אנגלית אחד · דף מדריך אחד — RTL, ניקוד, לוגו, פריסה, איכות PDF. **אוטומציה כן, עיוורון לא.**
