# brand_rules — שפת המותג "ניקה ספורט וקהילה"

מותג ספורט חברתי-חינוכי. אווירה: **Playful · Modern · Inclusive · High-Energy · Vibrant Neon · Clean UI · Rounded · Optimistic**.

## חובה / אסור

- **רקע:** MUST להיות לבן נקי `#FFFFFF` או אפור בהיר מאוד `#F5F5F5`. NEVER רקע כהה/שטוח.
- **קומפוזיציה:** מאווררת, הרבה white space. כרטיסיות MUST עם פינות מעוגלות + צללית רכה ("מרחפות").
- **צבעים — גרדיאנטים ניאוניים בלבד** (NEVER צבעים שטוחים כהים):
  - מגנטה-ורוד: `#E91E63 → #FF4081`
  - כחול-סגול: `#03A9F4 → #673AB7`
  - ליים-צהוב: `#8BC34A → #C0CA33`
  - שימוש: מילוי כפתורים/תגים, קו מתאר של אייקונים, הדגשת מילה בודדת בכותרת.
- **אייקונים:** MUST line-art / outline בלבד, **ללא מילוי**. עובי קו בינוני-דק אחיד. הקו צבוע בגרדיאנט מותג (NEVER שחור). צורות מעוגלות וידידותיות.
- **טיפוגרפיה:** Sans-serif מודרני נקי. כותרות עבות (Bold/Black) מעוגלות מעט, בכחול-כהה/שחור, עם אפשרות להדגיש מילה אחת בגרדיאנט. טקסט רץ דק ונקי.
  - מימוש נוכחי: `Rubik` (400–900) + `Varela Round` לכותרות ראווה. שניהם תומכי ניקוד/עברית.
- **צילום (אם משולב):** ילדים/נוער מגוונים, בתנועה, מחייכים, משתפים פעולה. אור טבעי, אותנטי. שכבת צבע מותג עדינה מותרת תוך שמירה על טבעיות.

## מימוש בקוד

כל חוקי המותג ממומשים ב-`templates/shared.css` (משתני `--g-magenta/--g-blue/--g-lime`, `.box`, `.levelbadge`, צללית `--shadow`).
האייקונים ב-`assets/icons/*.svg` — line-art עם `stroke="url(#grad)"` ו-`fill="none"`.

## סטטוס נכסים

`assets/icons/` מכיל סט **סטארטר** בסגנון המותג. יש להחליף בלוגו הרשמי (`assets/logo/`), פונטים רשמיים (`assets/fonts/`) ואיורי סצנה (`assets/illustrations/`) של NIKA. ראה `assets/README.md`.
